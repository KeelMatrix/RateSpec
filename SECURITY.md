# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately by emailing **keelmatrix@gmail.com** or by opening a private GitHub security advisory.

Do not disclose vulnerability details in a public issue. Useful reports include the affected package and version, target framework and runtime, reproduction steps or proof of concept, impact, and any suggested mitigation.

## Supported Versions

Security fixes are prioritized for the latest released package line. Older versions may receive fixes on a case-by-case basis.

Ordinary bugs and questions should use the public issue tracker. Do not send community-conduct reports to the security contact.
